# ToDoリストアプリ仕様

## 概要

ブラウザで動作する、日本語表示のシンプルなToDoリストアプリです。HTML、CSS、JavaScriptのみで構成され、サーバーや外部ライブラリを必要としません。

## ファイル構成

- `index.html`: 画面構造とタスク操作・保存処理
- `style.css`: レイアウト、配色、レスポンシブ表示、各種状態のスタイル

## 機能

- タスクの追加
  - 入力欄にタスク名を入力し、「追加する」を押すと一覧に追加します。
  - 前後の空白を除去して保存します。空の入力は追加しません。
  - 入力文字数の上限は120文字です。
- タスクの完了・未完了切り替え
  - 各タスクのチェックボックスで状態を切り替えます。
  - 完了したタスクは取り消し線で表示します。
- 未完了タスク数の表示
  - 見出し横の件数は未完了タスクの数です。
- 完了済みタスクの一括削除
  - 「完了済みを一括削除」を押すと、完了したタスクだけを一覧から削除します。
  - 削除対象がない場合、このボタンは無効です。
- タスクの保存と復元
  - タスクの追加、完了状態の変更、一括削除のたびにブラウザの`localStorage`へ保存します。
  - ページを開いたときに保存済みデータを読み込み、タスクと完了状態を復元します。
  - 保存データはブラウザの同じ保存領域（オリジン）で利用します。別のブラウザやプロファイルとは共有されません。

## 保存データ

- 保存キー: `simple-todo-tasks`
- 形式: JSON配列
- 各要素は次のプロパティを持ちます。
  - `text`: タスク名（文字列）
  - `completed`: 完了状態（真偽値）

```json
[
  { "text": "買い物をする", "completed": false }
]
```

## エラー時の動作

- 保存データを読み込めない、またはデータ形式が不正な場合はエラーを表示し、データを上書きしないよう追加・一括削除操作を無効にします。
- 保存に失敗した場合はエラーを表示します。操作中の画面状態は維持されますが、その変更が保存されたとは限りません。

## 画面・アクセシビリティ

- 日本語の画面と入力案内を表示します。
- 画面幅に応じてレイアウトを調整し、スマートフォンでも利用できるようにします。
- 入力欄、完了チェックボックス、操作ボタンにはラベルやキーボードフォーカス表示を設けています。
- 件数や保存エラーなどの状態変化は支援技術に通知します。
- OSで視差効果の低減が設定されている場合は、画面上のアニメーションを抑えます。

## 対象外

- タスク名の編集、個別削除、期限・優先度の設定
- タスクの検索、並べ替え、アカウント間の同期
- サーバーへのデータ送信やバックアップ
